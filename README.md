# NEXO

Organizador personal de finanzas y vehículo, en soles (PEN). App web instalable en iPhone desde Safari ("Agregar a pantalla de inicio"). Los datos se guardan solo en el dispositivo.

- `index.html`, `manifest.webmanifest`, `sw.js`, íconos: la app publicada con GitHub Pages.
- `src/nexo.html`: código fuente de la app. `src/build.py` genera los archivos publicados.
